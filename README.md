## What is Data Recovery Pilot?

[**Data Recovery Pilot**](https://datarecoverypilot.com) is file recovery software for **Windows 10 and 11**. It finds deleted, formatted and lost files on internal and external hard drives, SSDs and NVMe drives, USB flash drives, SD and microSD cards, and disk images.

What makes it different is **verification**: before you recover anything, each file is checked from start to end and labelled **Recoverable**, **Damaged at a given point**, or **Overwritten** — so you know which files will actually open, instead of finding out afterwards.

- **Free to scan.** Quick scan, deep scan, verification and preview are free with no limits. You only pay to save files.
- **Read-only.** The drive you recover from is opened read-only, and saving back to it is blocked.
- **Honest.** It tells you when a file is gone (for example, erased by SSD TRIM) instead of giving you a broken file.

## How to recover deleted files — step by step

1. **Choose the drive.** Every HDD, SSD, USB stick and memory card appears as soon as it's plugged in, each with a recovery outlook from *Excellent* to *Poor*, explained in plain words.
2. **Image it first if it's failing.** Clicking, slow or disconnecting? Make a disk image. Healthy areas are read first and damaged areas last; every later step works on the image instead of the weak drive.
3. **Quick scan.** Reads the file table and lists every file with its original name and folder — deleted files and emptied Recycle Bin items included.
4. **Deep scan, when needed.** For formatted, RAW or damaged drives it reads every sector. Results appear live, and progress is saved at least every 30 seconds, so a power cut costs very little.
5. **Check & preview.** Each deleted file is checked start to end and labelled *Recoverable*, *Damaged at a given point*, or *Overwritten*. Preview photos, video, PDFs and Office files before you decide.
6. **Recover — or repair first.** Save files to **another drive** with their folders. Damaged files go to **Repair**, which looks for the missing pieces and rebuilds them.

## What no software can recover

Being clear about limits saves you time:

- **SSD TRIM.** Most SSDs erase deleted space within minutes. Those files read back as zeros and no software can bring them back. Data Recovery Pilot detects this and tells you.
- **Overwritten space.** If new files were saved over a deleted one, that part is gone. It is marked *Overwritten* instead of being handed to you as a broken file.
- **Physical damage.** If a drive **clicks or grinds**, switch it off and contact a professional recovery lab. If it is only slow or disconnects, create a disk image first.

**To give your files the best chance:** stop using the drive, don't install anything onto it, don't format it, and recover to a different drive.

## Check your download

Each [release](https://github.com/DataRecoveryPilot/releases/releases) lists the SHA-256 checksum of its installer, and includes a `SHA256SUMS.txt` file. To check a downloaded file, run this in PowerShell and compare the result:

```powershell
Get-FileHash .\DataRecoveryPilot-Setup.exe -Algorithm SHA256
```

The value must match the checksum shown on the release and on the [download page](https://datarecoverypilot.com/download). Only download Data Recovery Pilot from this repository or from [datarecoverypilot.com](https://datarecoverypilot.com).

## FAQ

<details>
<summary><b>Can I try it before buying?</b></summary>

Yes. Scanning, deep scanning and previewing are free with no limits. You only need a license to save files.
</details>

<details>
<summary><b>Will scanning damage my drive or my files?</b></summary>

No. The drive is opened read-only, and recovering to the same drive is blocked.
</details>

<details>
<summary><b>I emptied the Recycle Bin. Can I get the files back?</b></summary>

Often, yes. Data Recovery Pilot rebuilds Recycle Bin items with their original names and folders, as long as their space hasn't been reused. → [Recycle Bin recovery](https://datarecoverypilot.com/recycle-bin-recovery)
</details>

<details>
<summary><b>I formatted my drive by mistake. Is everything gone?</b></summary>

Usually not. A quick format leaves most of the old file records. The deep scan rebuilds the old folders and names; on our test drive 99.7% of files went back to their original folders. → [Formatted drive recovery](https://datarecoverypilot.com/formatted-drive-recovery)
</details>

<details>
<summary><b>Windows says my drive is RAW or asks me to format it.</b></summary>

Don't format it. Open the drive in Data Recovery Pilot; a drive with no readable file system goes straight to a deep scan. → [RAW drive recovery](https://datarecoverypilot.com/raw-drive-recovery)
</details>

<details>
<summary><b>Why can't my files be recovered from an SSD?</b></summary>

Most SSDs use TRIM: Windows tells the SSD to erase deleted space, often within minutes. Those files read back as zeros and no software can bring them back. Data Recovery Pilot tells you when this has happened instead of giving you broken files. → [SSD data recovery](https://datarecoverypilot.com/ssd-data-recovery)
</details>

<details>
<summary><b>How do I know a recovered file will open?</b></summary>

Each file is checked from start to end before you recover it. "Recoverable · verified complete" means its whole structure passed the check. You can also preview it first.
</details>

<details>
<summary><b>A file says "Damaged". What can I do?</b></summary>

Select it and click **Repair**. Repair searches the drive for the missing piece and rebuilds the file, then tells you how sure it is: *Exact*, *Structural* or *Weak*.
</details>

<details>
<summary><b>My drive is clicking, slow or keeps disconnecting.</b></summary>

If it clicks or grinds, switch it off and contact a recovery lab. If it's only slow or disconnects, create a disk image first; the imaging is gentle and can resume after a disconnect. → [Failing hard drive recovery](https://datarecoverypilot.com/failing-hard-drive-recovery)
</details>

<details>
<summary><b>The deep scan takes hours. What if the power goes out?</b></summary>

Progress is saved at least every 30 seconds. Open the app again and choose **Resume**; it carries on where it stopped.
</details>

<details>
<summary><b>Can I recover to the same drive?</b></summary>

No. Saving to the drive you recover from could overwrite the files you're trying to get back, so the app blocks it.
</details>

<details>
<summary><b>Does it work on Mac or Linux drives?</b></summary>

Not yet. It supports NTFS, exFAT and FAT drives, which covers Windows drives, USB sticks and memory cards.
</details>

<details>
<summary><b>Can I move my license to a new PC?</b></summary>

Yes. Open **License** in the app and choose **Remove license from this PC**, then activate on the new one.
