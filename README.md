## Requirements

- Windows 10 or 11 (64-bit)
- Install it on a **different drive** from the one you want to recover, so the installer does not overwrite lost files.

The free version scans and previews every recoverable file. A license is needed to save files — see [pricing](https://datarecoverypilot.com/pricing).

## Check your download

Each release lists the SHA-256 checksum of its installer. To check a downloaded file, run this in PowerShell and compare the result:

```powershell
Get-FileHash .\DataRecoveryPilot-Setup.exe -Algorithm SHA256
```
